# PiStreamTerminal

<img src="assets/icons/pistream-128.png" alt="PiStreamTerminal icon" width="112">

**Вычисление числа π в отдельном окне. Локально, с нужной точностью.**

Rust · egui / eframe 0.35 · GMP / MPFR · macOS / Windows / Ubuntu

PiStreamTerminal 0.2 добавляет настольный интерфейс в бело-коралловой палитре,
светлую и тёмную темы, историю сессии и готовую сборку `.app`.
Вычисления и результаты не отправляются в сеть.

## Запуск

Для установочного пакета: `make setup`, затем `make doctor` и `make local`.
Сборщику нужен Python 3.11+; готовому приложению Python и терминал не нужны.


| Команда | Что делает |
| --- | --- |
| `make` / `make dev` | Собирает и запускает окно приложения |
| `make build` | Собирает GUI + CLI и установщик текущей ОС |
| `make run` | Открывает готовую сборку без пересборки |
| `make start` | Собирает release и открывает приложение |
| `make cli` | Запускает прежний консольный интерфейс |
| `make check` | Форматирование, строгий Clippy и тесты |

На macOS готовое приложение: `dist/PiStreamTerminal.app`.
Оно запускается двойным щелчком и не требует открытого терминала.
Все пути сборки вычисляются относительно проекта: папку можно перенести целиком.
Не переносите `target/` и `dist/` в Git.

## Возможности окна

- Четыре алгоритма: Чудновский с Binary Splitting, формула Мачина,
  Гаусс—Лежандр / AGM, прямой ряд Чудновского.
- От **1 до 1 000 000 знаков после запятой**. Вычисление работает в отдельном потоке.
- Остановка кнопкой или Esc; отмена проверяется между математическими операциями.
- Копирование полного числа и сохранение `.txt` через системный диалог.
- Последние 12 завершённых результатов в истории; открытие результата без пересчёта.
- В окне показаны первые 2 000 знаков большого числа; копирование и файл содержат всё число.
- Светлая / тёмная тема. Настройки и история хранятся в памяти до закрытия окна.
- Запуск расчёта: Cmd+Enter на Mac или Ctrl+Enter на Windows/Linux.

Результат округляется до выбранного количества знаков. Время в интерфейсе
измеряется для конкретного завершённого расчёта; обещаний фиксированной производительности нет.

## Разработка

Нужны Rust **1.94+**, инструменты компиляции C/C++ для GMP/MPFR
(на macOS — Xcode Command Line Tools) и Cargo.
На первом запуске Cargo может собирать GMP/MPFR из исходников.

```sh
cargo run --locked --bin PiStreamTerminal
cargo run --locked --bin pistream-cli
cargo fmt --all -- --check
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked
```

Алгоритмы проверяются независимо от GUI, в том числе по `rug::float::Constant::Pi`
из MPFR для нескольких точностей. Бенчмарки запускаются отдельно: `cargo bench`.

## Иконка и упаковка

Исходная иконка: `assets/icons/pistream-1024.png`.
Готовые PNG, `.icns` и `.ico` входят в репозиторий.
Для повторного экспорта на macOS: `make icons` (Node.js и системный `sips`).
Обычная сборка и работа приложения не требуют Node.js.

Скрипт `scripts/build-macos.sh` создаёт `.app` и ZIP, проверяет plist и подпись.
По умолчанию подпись локальная ad hoc. При наличии Developer ID можно передать
`PISTREAM_SIGNING_IDENTITY`. Публикация и нотарификация скриптом не выполняются.

Windows: `scripts/build-windows.ps1` подготовлен для GNU toolchain с MSYS2,
поскольку GMP/MPFR требует C-инструментов. Нужны Rust target
`x86_64-pc-windows-gnu`, `gcc`, `make`, `m4`, `windres` в PATH.
Проверка реального EXE и его запуска выполняется на Windows; macOS-сборка этого не подтверждает.

## Консольная совместимость

Прежние `quick_run.sh`, `run_with_monitoring.sh` и тестовые скрипты обращаются к
отдельной цели `pistream-cli`. Режимы Ultra Scale и потоковая запись остаются
в консольной версии; они не запускаются из окна автоматически.

```sh
printf '2\n100\n' | cargo run --release --locked --bin pistream-cli
```

# Pi Calculator - Высокоточное вычисление π

Продвинутый калькулятор числа π с множественными оптимизированными алгоритмами.

## 🚀 Новые алгоритмы

### 1. Чудновский (Binary Splitting) - самый быстрый для больших чисел
- **Сложность**: O(M(n) log n) вместо O(M(n) n)
- **Рекурсивное разложение ряда**
- **В разы быстрее для >1000 знаков**

### 2. Формула Мачина - классический быстрый алгоритм
- **Формула**: π/4 = 4×arctan(1/5) - arctan(1/239)
- **Отличная производительность для средних значений**

### 3. Алгоритм Борвейна - квадратичная сходимость
- **Удваивает точность на каждой итерации**
- **Очень быстрый для небольших и средних значений**

## ⚡ Оптимизации оригинального алгоритма

- Использование `Integer` для точных промежуточных вычислений
- Правильная обработка неполных операций rug
- Улучшенная проверка сходимости
- Оптимизированное управление памятью

## 🎯 Улучшения интерфейса

- **Выбор алгоритма при запуске**
- **Измерение времени выполнения**
- **Умный вывод результата**
- **Возможность сохранения в файл**
- **Улучшенные прогресс-бары**

## 📊 Производительность

- **Binary Splitting Чудновского**: лучший для >1000 знаков
- **Борвейн**: отличный для средних значений
- **Мачин**: хорош для классических вычислений
- **Оптимизированный наивный**: улучшенная версия оригинала

> **Теперь ваша программа работает в несколько раз быстрее**, особенно для больших количеств знаков! Binary Splitting алгоритм Чудновского является самым быстрым из существующих методов для вычисления π с высокой точностью.

## Использование

### Быстрый старт
```bash
cargo run --release  # Рекомендуется для лучшей производительности
```

При запуске программа предложит:
1. **Выбрать алгоритм** (1-4, по умолчанию Binary Splitting)
2. **Ввести количество знаков** после запятой

### Примеры использования
```bash
# Автоматический режим с Binary Splitting (самый быстрый)
echo -e "2\n1000" | cargo run --release

# Тестирование разных алгоритмов
echo -e "1\n100" | cargo run --release  # Наивный Чудновский
echo -e "3\n100" | cargo run --release  # Формула Мачина
echo -e "4\n100" | cargo run --release  # Алгоритм Борвейна
```

### Рекомендации по выбору алгоритма
- **< 100 знаков**: Любой алгоритм (рекомендуется Борвейн или Мачин)
- **100-1000 знаков**: Binary Splitting или Борвейн
- **> 1000 знаков**: Binary Splitting - безусловно лучший выбор

## Алгоритмы

### 1. Чудновский (Binary Splitting)
**Формула**: π = 426880√10005 / Σ[k=0 to ∞] ((-1)^k * (6k)! * (13591409 + 545140134k)) / ((3k)! * (k!)^3 * 640320^(3k))

**Оптимизация**: Binary Splitting рекурсивно разбивает ряд на подинтервалы, сокращая сложность с O(M(n) n) до O(M(n) log n).

### 2. Формула Мачина
**Формула**: π/4 = 4×arctan(1/5) - arctan(1/239)

Использует разложение arctan в ряд Тейлора для быстрой сходимости.

### 3. Алгоритм Борвейна (AGM)
Итеративный алгоритм с квадратичной сходимостью, основанный на арифметико-геометрическом среднем.

### 4. Чудновский (наивный)
Прямая реализация ряда Чудновского с оптимизациями памяти и точности.

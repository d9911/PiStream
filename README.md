# Pi Calculator (Chudnovsky Algorithm)

Высокоточный калькулятор числа π с использованием алгоритма Чудновских.

## Особенности

- Использует алгоритм Чудновских для быстрого вычисления π
- Поддерживает произвольную точность (до тысяч знаков)
- Показывает прогресс вычислений с помощью progress bar
- Написан на Rust с использованием библиотеки `rug` для высокоточной арифметики

## Настройка в IntelliJ IDEA

### Требования

1. **IntelliJ IDEA** (Community или Ultimate)
2. **Rust Plugin** - установите из Marketplace:
   - File → Settings → Plugins
   - Найдите "Rust" и установите официальный плагин от JetBrains

### Открытие проекта

1. Откройте IntelliJ IDEA
2. File → Open
3. Выберите папку `PiStreamTerminal`
4. IDEA автоматически обнаружит Cargo.toml и настроит проект

### Настройка Run Configuration

Проект уже содержит готовую конфигурацию запуска в `.idea/workspace.xml`:

1. В верхней панели выберите "Run pi-number"
2. Нажмите зеленую кнопку ▶️ для запуска
3. Или используйте Shift+F10

### Альтернативная настройка Run Configuration

Если автоматическая конфигурация не работает:

1. Run → Edit Configurations
2. Нажмите "+" → Cargo Command
3. Заполните поля:
   - Name: `Run pi-number`
   - Command: `run`
   - Working directory: путь к проекту
4. Apply → OK

## Использование

Запустите программу и введите количество знаков после запятой:

```bash
cargo run
```

Или через терминал с автоматическим вводом:
```bash
echo "100" | cargo run  # Вычислить π с 100 знаками
```

## Зависимости

- `rug = "1.22"` - Высокоточная арифметика (обертка над GMP/MPFR)
- `indicatif = "0.17"` - Progress bar для терминала

## Алгоритм

Использует формулу Чудновских:

π = 426880√10005 / Σ[k=0 to ∞] ((-1)^k * (6k)! * (13591409 + 545140134k)) / ((3k)! * (k!)^3 * 640320^(3k))

Этот алгоритм сходится очень быстро - каждая итерация добавляет примерно 14 правильных десятичных знаков.

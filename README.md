# Pi Calculator - Высокоточное вычисление π

Продвинутый калькулятор числа π с множественными оптимизированными алгоритмами.

## 🚀 Новые алгоритмы

### 1. Чудновский (Binary Splitting) - самый быстрый для больших чисел
- **Сложность**: O(M(n) log n) вместо O(M(n) n)
- **Рекурсивное разложение ряда**
- **В разы быстрее для >1000 знаков**

### 2. Формула Мачина - классический быстрый алгоритм
- **Формула**: π/4 = 4×arctan(1/5) - arctan(1/239)
- **Отличная производительность для средних значений**

### 3. Алгоритм Борвейна - квадратичная сходимость
- **Удваивает точность на каждой итерации**
- **Очень быстрый для небольших и средних значений**

## ⚡ Оптимизации оригинального алгоритма

- Использование `Integer` для точных промежуточных вычислений
- Правильная обработка неполных операций rug

- Оптимизированное управление памятью

## Настройка в IntelliJ IDEA

### Требования

1. **IntelliJ IDEA** (Community или Ultimate)
2. **Rust Plugin** - установите из Marketplace:
   - File → Settings → Plugins
   - Найдите "Rust" и установите официальный плагин от JetBrains

### Открытие проекта

1. Откройте IntelliJ IDEA
2. File → Open
3. Выберите папку `PiStreamTerminal`
4. IDEA автоматически обнаружит Cargo.toml и настроит проект

### Настройка Run Configuration

Проект уже содержит готовую конфигурацию запуска в `.idea/workspace.xml`:

1. В верхней панели выберите "Run pi-number"
2. Нажмите зеленую кнопку ▶️ для запуска
3. Или используйте Shift+F10

### Альтернативная настройка Run Configuration

Если автоматическая конфигурация не работает:

1. Run → Edit Configurations
2. Нажмите "+" → Cargo Command
3. Заполните поля:
   - Name: `Run pi-number`
   - Command: `run`
   - Working directory: путь к проекту
4. Apply → OK

## Использование

### Быстрый старт
```bash
cargo run --release  # Рекомендуется для лучшей производительности
```

При запуске программа предложит:
1. **Выбрать алгоритм** (1-4, по умолчанию Binary Splitting)
2. **Ввести количество знаков** после запятой

### Примеры использования
```bash
# Автоматический режим с Binary Splitting (самый быстрый)
echo -e "2\n1000" | cargo run --release

# Тестирование разных алгоритмов
echo -e "1\n100" | cargo run --release  # Наивный Чудновский
echo -e "3\n100" | cargo run --release  # Формула Мачина  
echo -e "4\n100" | cargo run --release  # Алгоритм Борвейна
```

### Рекомендации по выбору алгоритма
- **< 100 знаков**: Любой алгоритм (рекомендуется Борвейн или Мачин)
- **100-1000 знаков**: Binary Splitting или Борвейн
- **> 1000 знаков**: Binary Splitting - безусловно лучший выбор

## Алгоритмы

### 1. Чудновский (Binary Splitting)
**Формула**: π = 426880√10005 / Σ[k=0 to ∞] ((-1)^k * (6k)! * (13591409 + 545140134k)) / ((3k)! * (k!)^3 * 640320^(3k))

**Оптимизация**: Binary Splitting рекурсивно разбивает ряд на подинтервалы, сокращая сложность с O(M(n) n) до O(M(n) log n).

### 2. Формула Мачина
**Формула**: π/4 = 4×arctan(1/5) - arctan(1/239)

Использует разложение arctan в ряд Тейлора для быстрой сходимости.

### 3. Алгоритм Борвейна (AGM)
Итеративный алгоритм с квадратичной сходимостью, основанный на арифметико-геометрическом среднем.

### 4. Чудновский (наивный)
Прямая реализация ряда Чудновского с оптимизациями памяти и точности.

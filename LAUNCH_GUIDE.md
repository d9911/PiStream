# 🚀 Руководство по запуску PiStreamTerminal

## 📋 Доступные скрипты запуска

### 1. ⚡ Быстрый запуск (рекомендуется для тестирования)
```bash
./quick_run.sh
```
- Быстрая компиляция в debug режиме
- Немедленный запуск
- Подходит для небольших вычислений

### 2. 📊 Запуск с мониторингом (для больших вычислений)
```bash
./run_with_monitoring.sh
```
- Компиляция в release режиме (оптимизированная)
- Детальный мониторинг процесса
- Статистика использования ресурсов
- Автоматическое отслеживание прогресса

### 3. 🔍 Мониторинг существующего процесса
```bash
./monitor_pi.sh
```
- Мониторинг уже запущенного процесса
- Возможность прерывания
- Статистика в реальном времени

## 🎯 Рекомендации по использованию

### Для небольших вычислений (< 1M знаков):
```bash
./quick_run.sh
```

### Для больших вычислений (> 100M знаков):
```bash
./run_with_monitoring.sh
```

## 🛑 Прерывание вычислений

### Способ 1: Ctrl+C
- Нажмите `Ctrl+C` в терминале где запущено приложение
- Процесс корректно завершится с сохранением частичных результатов

### Способ 2: Через мониторинг
```bash
./monitor_pi.sh
# Затем нажмите 'i' для прерывания
```

### Способ 3: Через системные команды
```bash
# Найти процесс
ps aux | grep PiStreamTerminal

# Прервать процесс
kill -INT <PID>
```

## 📁 Файлы результатов

После вычислений создаются следующие файлы:

- `pi_stream_<digits>_digits.txt` - потоковый файл с блоками
- `pi_<digits>_digits_STREAMING.txt` - читаемый файл с результатом

## 🔧 Устранение проблем

### Процесс "завис"
1. Проверьте мониторинг: `./monitor_pi.sh`
2. Если нет прогресса > 30 секунд - это нормально для больших вычислений
3. Для прерывания используйте Ctrl+C

### Недостаточно памяти
1. Уменьшите количество знаков
2. Используйте алгоритм с меньшими требованиями к памяти
3. Закройте другие приложения

### Медленные вычисления
1. Используйте release режим: `cargo build --release`
2. Выберите более быстрый алгоритм (Binary Splitting)
3. Уменьшите размер блока в коде

## 📊 Мониторинг ресурсов

### CPU и память:
```bash
top -p $(pgrep PiStreamTerminal)
```

### Дисковое пространство:
```bash
du -h pi_stream_*_digits.txt
```

### Сетевые операции (если есть):
```bash
netstat -an | grep PiStreamTerminal
```
